# Notes

Personal learning notes. Each directory is its own curriculum: notes, exercises, and a plan for what comes next.

| Directory | What it covers |
| --- | --- |
| [c#-dot-net-interview-prep](c%23-dot-net-interview-prep/) | C# and .NET for interviews and for real understanding: how to reason about trade-offs, then the language, runtime, and backend topics behind the answers. |
| [from-python-to-agents](from-python-to-agents/) | Python through professional Python, backend work, LLMs, RAG, and agents, aimed at AI Engineer / Forward Deployed Engineer work. |
| [golang-or-go-home](golang-or-go-home/) | Go from language foundations through HTTP APIs and middleware, on the way to production backend services. |
| [nosql-database-roadmap](nosql-database-roadmap/) | NoSQL from distributed-systems ideas and data models through MongoDB, Redis, DynamoDB, Cassandra, and Neo4j — trade-offs, not product commands. |
| [react-angular-roadmap](react-angular-roadmap/) | JavaScript, then TypeScript, then React and Angular, in dependency order so later concepts are not used before they are introduced. |
| [sql](sql/) | SQL Server indexing and query performance: how indexes work, how to choose them, and how to diagnose what the engine is actually doing. Notes live in [sql/indexing](sql/indexing/). |
| [system-design](system-design/) | Backend system-design interview practice (worked designs) plus a fundamentals curriculum in [system-design/01-fundamentals](system-design/01-fundamentals/) so later designs can justify each component. |

Most directories also have a `plan.md` (the full curriculum) and a `progress.md` (where the notes currently are). Start with that directory’s `README.md` when it has one.
