# From Python to Agents 🤖

A hands-on learning journey from **Python beginner to building AI agents**.

The goal is to learn Python properly, then build on it to understand and create modern AI applications, LLMs, RAG systems, and agents.

## Learning Path

```text
Python
  ↓
Professional Python
  ↓
Backend Development
  ↓
AI & LLM Foundations
  ↓
LLM Applications
  ↓
RAG
  ↓
AI Agents
  ↓
Production AI
```

This repository contains:

- 📝 Notes
- 💻 Code and exercises
- 🧪 Experiments
- 🚀 Projects

The end goal is to build the skills needed to work as an **AI Engineer or Forward Deployed Engineer (FDE)**.
