# golang-or-go-home 🐹

A personal learning repository documenting my journey learning the Go programming language — from the basics to real-world projects.

## What's in here?

This repo contains small programs, exercises, and experiments written as I progress through Go concepts, including:

- Variables, types, and functions
- Control flow and loops
- Structs, interfaces, and methods
- Error handling
- Concurrency with goroutines and channels
- And more as I go...

## Prerequisites

- [Go](https://go.dev/dl) 1.20+
- [Go extension for VS Code](https://marketplace.visualstudio.com/items?itemName=golang.go)

## Running any program

```
go run main.go
```

## The Language Server — gopls

When you write Go code in Bob, you're not alone. In the background, a program called gopls (pronounced "go please") is running silently. It's a language server — it reads your code in real time and talks to the editor to provide:

✅ Autocomplete  
✅ Red underlines on errors  
✅ Go to definition (Cmd+Click)  
✅ Auto import/remove of packages  
✅ Hover documentation  
✅ Formatting on save  

It's why the editor feels "smart" about Go specifically.
